# Visual Beads

A Morse code bead bracelet visualizer. Type any words and see them spelled out in beads, with dots and dashes as the letter beads and background beads filling the gaps.

## What it does

- Pick colors for background, dot, dash and word-spacer beads
- Choose a bead type: 6×2 mm or 6×3 mm sliced cylinders, or 4/6/8 mm rounds
- Set beads per dot and dash, and the spacing inside letters, between letters and between words
- Pick a bracelet length and how to handle leftover length (fill and center, repeat, or message only)
- See a ring preview, a flat strand view with bead counts, and a numbered stringing order you can copy

Settings are saved in your browser.

## Use it

Open `index.html` in a browser. No build step. To host it, turn on GitHub Pages for the `main` branch.
